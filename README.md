# Daily Desk

Daily Desk is a minimal personal to-do application focused on daily task planning, backlog management, and the satisfaction of crossing tasks off like a physical notebook.

## Current Features

- Add tasks
- Today / Backlog separation
- Complete tasks
- Move tasks between Today and Backlog
- Delete tasks
- LocalStorage persistence
- Close Day flow

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- LocalStorage

## Planned Features

- Task editing
- Categories
- Priority levels
- Daily summary
- Completed task history
- Weekly review
